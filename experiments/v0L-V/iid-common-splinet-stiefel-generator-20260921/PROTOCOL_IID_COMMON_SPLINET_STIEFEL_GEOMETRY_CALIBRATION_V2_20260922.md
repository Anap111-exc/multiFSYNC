# iid-common-Splinets-Stiefel 几何校准协议 v2

日期：2026-09-22  
状态：development geometry calibration；不授权生成正式数据或运行模型拟合。

## 1. v1 证据与本轮问题

v1 使用 `J_truth=8`、三次、非周期的公共 `Splinets` 正交系统，并在
8 维球面上均匀生成 Stiefel 系数。500 次无拟合审计确认了：

- 块内连续 $L^2$ Gram 达到机器精度；
- 三个角色块来自可交换分布；
- 块间没有被错误地强制正交；
- 但真函数投影到当前 `K=5` O'Sullivan 拟合空间的相对误差下界过高，
  中位数约 `0.670`、95% 分位数约 `0.821`。

因此 v1 失败结果保留，不按模型恢复结果挑选函数种子。本轮只回答：能否继续
使用 `Splinets`，通过一个全局、角色无关的平滑几何分布，同时避免
“真函数过粗糙”和“不同因子块近乎相同”两个相反问题。

## 2. 只使用 Splinets 官方对象链

本轮不另建样条框架。对公共正交系统 $S(t)$，使用：

- `Splinets::splinet()` 构造连续 $L^2$ 正交 B 样条系统；
- 两次 `Splinets::deriva()` 得到二阶导数对象；
- `Splinets::gramian()` 精确计算连续 Gram 和曲率矩阵；
- `Splinets::lincomb()` 构造随机线性组合；
- `Splinets::evspline()` 在审计网格直接求值。

base R 的 `eigen()` 和 `qr()` 只承担系数矩阵运算。

令

\[
P_2=\int_0^1 S''(t)S''(t)^{\mathsf T}\,dt
   =V\,\mathrm{diag}(d_1,\ldots,d_J)V^{\mathsf T}.
\]

对固定的全局曲率权重 $\alpha\geq0$，定义

\[
W_\alpha=V\,\mathrm{diag}\left[
\left\{1+\alpha d_k/\operatorname{median}(d)\right\}^{-1/2}
\right]V^{\mathsf T}.
\]

每个完整函数因子块 $q$ 独立抽取

\[
E_q\in\mathbb R^{J\times M_q},\quad E_{q,km}\sim N(0,1),
\qquad Z_q=W_\alpha E_q,
\]

再以薄 QR 得到 $Q_q$。最终

\[
\Phi_q(t)=S(t)Q_q,\qquad Q_q^{\mathsf T}Q_q=I,
\]

故平滑加权只改变随机子空间分布，不破坏块内连续 $L^2$ 正交。
`alpha=0` 精确退化为 v1 的均匀 Stiefel 机制。

## 3. 固定候选

所有候选固定 `J=8`、三次样条、三个角色块、每块 `M=2`：

| candidate_id | boundary | alpha | 用途 |
|---|---:|---:|---|
| NP_U | non-periodic | 0 | v1 基线复核 |
| NP_S10 | non-periodic | 10 | 中等曲率加权 |
| NP_S30 | non-periodic | 30 | 较强曲率加权 |
| NP_S100 | non-periodic | 100 | 检查平滑与近重合的极端权衡 |
| P_U | periodic | 0 | 周期公共系统基线 |
| P_S1 | periodic | 1 | 弱曲率加权 |
| P_S3 | periodic | 3 | 中等曲率加权 |
| P_S10 | periodic | 10 | 检查周期系统的近重合尾部 |

非周期系统以 `J+4` 个等距 knots 构造；周期系统以 `J+1` 个等距 knots
构造。两者均由 `splinet(..., degree=3, norm=TRUE)` 实现并核验实际返回维数
为 8。周期候选是明确的边界敏感性候选，不因数值表现较好就自动成为主场景。

## 4. 独立无拟合审计

- 审计 RNG 种子：`20260922`；
- 每候选独立生成 `500` 次；
- 每次三个角色块，每块 `M=2`；
- 评价网格：201 点；
- 当前拟合空间参考：`K=5` O'Sullivan，即含常数、线性零空间及 5 个
  非线性惩罚方向；
- 不生成响应、不调用 `multi_cavi()`、不读取任何真值恢复评价。

记录：

1. 块内连续 Gram 和 201 点梯形 Gram 误差；
2. 二阶导数连续粗糙度；
3. 两端各 10% 区间能量；
4. 投影到当前 O'Sullivan 空间的相对 $L^2$ 误差下界；
5. 块间最大典型相关及其尾部比例；
6. 三个角色块的分布可交换性。

## 5. 预先固定的有效性门槛

候选必须同时满足：

1. 连续 Gram 最大误差不超过 `1e-8`；
2. 全部指标有限；
3. 粗糙度、边界能量和投影误差的角色均值范围除以合并标准差均不超过
   `0.25`；
4. 投影误差的总体中位数不超过 `0.25`，95% 分位数不超过 `0.60`；
5. 块间最大典型相关的 95% 分位数不超过 `0.98`，超过 `0.95` 的比例不超过
   `0.10`；
6. 不出现达到 `1-1e-8` 的数值重复子空间；块间典型相关中位数必须大于
   `0.10`，以排除错误的全局块间正交。

若多个候选通过，先选较小 `alpha`；同一 `alpha` 下优先非周期候选。若只有
周期候选通过，只能得出“周期候选具有可用几何”，是否接受周期边界作为论文
主场景必须由后续科学决策单独确认。

## 6. 停止规则

- 本轮不修改模型、先验、CAVI、ELBO、初始化、载荷生成或评价公式；
- 不按拟合结果更改 `alpha`；
- 若没有候选通过，停止并报告当前 `K=5` 与真值函数空间的冲突，不继续增加
  候选网格；
- 若有候选通过，也只允许随后实现该候选并做生成器单元测试和微型
  generation-only smoke；任何模型桥接拟合需另行批准。
