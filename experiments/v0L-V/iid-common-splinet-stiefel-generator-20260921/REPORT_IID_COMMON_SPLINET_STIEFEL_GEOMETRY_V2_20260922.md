# iid-common-Splinets-Stiefel 无拟合几何审计报告 v2

日期：2026-09-22  
范围：只读函数几何与数据生成代码；没有生成正式数据，没有运行模型拟合。

## 1. 结论先行

1. 新生成思路的核心部分成立：`Splinets` 可以为任意数量的共享/特异因子块
   提供同分布、独立生成、块内连续 $L^2$ 正交的随机 B 样条函数。
2. v1 的“非周期、`J=8`、均匀 Stiefel”不能直接投入模拟。它虽然连续正交且
   角色可交换，但相对当前 `K=5` O'Sullivan 拟合空间过于粗糙；v2 独立复核的
   投影误差下界中位数为 `0.670`、95% 分位数为 `0.825`。
3. 单纯加强非周期函数的曲率权重不能同时解决问题：函数变得可表示时，不同
   因子块又过度集中到少数平滑方向，近重合率超过预注册门槛。
4. 在固定 `K=5` 的八个候选中，只有 `P_S3` 同时通过可表示性、跨块重合、
   连续正交和角色可交换性门槛。它使用共同的周期三次 Splinets 系统和
   `alpha=3` 的二阶曲率权重。
5. 这不是自动采用 `P_S3` 的授权。把全部真特征函数设为周期函数是一个科学
   边界假设，需要与另一条路线比较：保留非周期真值，同时把未来模拟的拟合
   `K` 从 5 提高到约 9。

所有候选均满足：

- 连续 Gram 最大误差不超过 `1e-8`；
- 数值有限；
- 三个角色在粗糙度、边界能量和投影误差上的标准化均值范围不超过
  `0.25`；
- 不同块没有被错误地全局正交，也没有数值上完全相同的子空间。

因此失败不是 `Splinets` 正交化错误，也不是角色分布不一致；它是
“当前拟合空间可表示性”与“跨块随机多样性”之间的真实几何权衡。

## 3. 为什么曲率权重不是另造样条方法

实现仍完全依赖 `Splinets`：

- `splinet()` 给出连续正交 B 样条系统；
- `deriva(deriva(os))` 给出二阶导数对象；
- `gramian()` 给出精确曲率矩阵；
- `lincomb()` 和 `evspline()` 构造并直接评价函数。

曲率权重只定义“在这个现成正交系统内如何随机抽取子空间”。随后 QR 保证
$Q_q^{\mathsf T}Q_q=I$，所以块内连续正交仍是精确的。三个角色使用同一组
全局参数并独立抽样，角色可交换性没有被破坏。

## 4. 额外的 K 敏感性（探索性，不参与 v2 候选选择）

为分离“周期边界”和“拟合空间维数”，在另一个 RNG 种子下对非周期候选做了
150 次无拟合探索。结果显示：

- 非周期 `alpha=3` 在 `K=5` 时投影误差中位数/95%分位数约为
  `0.420/0.601`；
- 提高到 `K=7` 后约为 `0.266/0.473`；
- 提高到 `K=9` 后约为 `0.155/0.295`；
- 其跨块 `cross>0.95` 比例约 `0.049`，不随 `K` 改变，低于 0.10 门槛。

这说明非周期机制本身并非无解；它与当前 `K=5` 的组合不合适。`K=9` 仍不是
与真值生成基完全相同的空间，因而不是“用同一基生成并拟合”，但会增加每轮
CAVI 的矩阵维数与后续验证工作。该探索没有改变 v2 的正式选择结果。

## 5. 需要作者决定的科学分叉

### 路线 A：保持未来模拟 `K=5`，采用 P_S3

优点：

- v2 唯一完整通过的候选；
- 不改变当前拟合配置和计算维数；
- 周期 B 样条仍是 B 样条，且函数型模拟中周期真函数并不罕见。

代价：

- 所有共享和特异真特征函数都满足周期边界；
- 若应用时间域并无周期含义，这个假设可能显得人为；
- 需要在论文中明确周期边界，而不能仅称“随机 B 样条”。

### 路线 B：保持非周期真值，未来模拟采用 K=9

优点：

- 不给所有因子过程施加周期边界；
- 初步几何显示非周期 `alpha=3` 在 `K=9` 同时具有较低投影误差和可接受的
  跨块多样性；
- 生成基和拟合基仍不相同。

代价：

- `K` 从 5 增至 9，需要重新做微型运行时间、数值稳定性和 G12 兼容检查；
- 不能把此前 `K=5` 的拟合证据直接当作新配置证据；
- 后续论文实验成本会增加。

当前建议是：在作者确认 A 或 B 前，不把 v1 构造提升为正式生成器，也不启动
任何桥接拟合。历史 `legacy_dense_gram` 和 `jaoua_splinets` 结果均不受影响。
