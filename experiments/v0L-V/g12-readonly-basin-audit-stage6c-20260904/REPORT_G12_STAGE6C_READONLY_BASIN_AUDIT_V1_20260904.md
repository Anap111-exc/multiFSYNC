# G12 Stage 6C 只读盆地审计报告 v1

日期：2026-09-04

## 1. 审计边界

本轮只读审计没有启动新 fit、refit 或 continuation，也没有修改模型、先验、CAVI、G12 初始化、退火、400-sweep 上限或 ELBO。真值盲阶段只读取已有 `fit.rds` 与 `terminal_record.rds`：

- Stage 6A：3 个拟合上界配置，每配置 12 个起点，共 36 个端点；
- Stage 6B v2：5 个拟合上界配置，每配置 4 个起点，共 20 个端点。

Stage 6A 的全数据拟合与 Stage 6B 的留出训练集拟合始终分层处理，未混合成同一盆地。

### 4.2 `modal_basin_then_elbo` 与原最大 ELBO

在 8 个审计层中，原最大有效普通 ELBO 与“最大盆地内最大 ELBO”的结果如下；0.80 与 0.90 阈值结论相同。

| 结果 | 原最大 ELBO | 最大盆地后 ELBO |
|---|---:|---:|
| 在存在 core-truth 端点的层中选中 core truth | 7/7 | 6/7 |
| 在存在精确因子结构端点的层中选中精确结构 | 4/4 | 3/4 |
| 在存在结构与 M 同时精确端点的层中选中精确联合结果 | 2/2 | 1/2 |
| 8 层平均 dense signal NRMSE | 0.76934 | 0.76872 |
| 8 层平均 feature ISE | 0.30987 | 0.29361 |
| 8 层平均协方差算子相对误差 | 1.95866 | 1.87743 |

连续误差均值的小幅改善由不同层的相反变化抵消而来，不能掩盖精确恢复次数下降：

- Stage 6A `L3M2`：原 ELBO winner `__07` 是单例；模态盆地代表 `__02` 仍恢复 core truth，并把 dense NRMSE 从 0.8943 降至 0.7335、feature ISE 从 0.5805 降至 0.4509、协方差误差从 2.3590 降至 1.5406。
- Stage 6A `L1M2`：正确盆地只有 2 个起点，错误模态盆地有 3 个起点。原 winner `__03` 精确恢复结构与 M；模态代表 `__02` 丢失 core truth，dense NRMSE 从 0.2303 恶化到 0.3861，协方差误差从 0.4449 恶化到 0.6135。

## 5. 结论

1. “跨起点重复出现”是有价值的优化诊断，但本轮证据不支持把最大盆地设成固定维度内的硬选择门槛。
2. 盆地频率不等于科学正确性；在真实上界 `L1M2` 中，错误结构反而是 3/12 的最大盆地，而正确结构位于 2/12 的次大盆地。
3. 4 个起点不足以估计盆地支持；Stage 6B 的五个配置在三个阈值下均没有大小至少为 2 的盆地。
4. 当前最大有效普通 ELBO 的固定配置内规则不应因 Stage 6C 被替换。稳定性应保留为报告项、异常标记或后续独立协议的辅助量。
5. 本轮只有一个开发数据种子，且盆地定义采用三个角色最小相似度；不能据此宣称最大 ELBO 一般最优，也不能据此建立论文级维度选择规则。

## 6. 对后续选择流程的影响

Stage 6B 的分工仍应解释为：

- 每个预注册拟合上界配置内，先按最大有效普通 ELBO 选一个起点代表；
- 不同拟合上界配置之间不用普通 ELBO，而用完全真值盲的留出预测风险和 one-standard-error 简约规则比较；
- 当前 `modal_basin_then_elbo` 不进入正式流程；
- 若以后研究“用留出风险同时选起点和维度”，必须使用独立/嵌套验证或预注册聚合规则，避免在同一小留出集上从大量起点中取最小值所产生的选择偏差。
