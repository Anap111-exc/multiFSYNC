# Stage 7A: shared covariate-effect simulation, paired truth-shape sensitivity

Registered 2026-09-19 before data generation and fitting. This is a development
simulation, not a replacement for the frozen v0L-V protocol or a claim of
paper-level Monte Carlo evidence. The user authorized starting this experiment
on 2026-09-19. Truth remains sealed until a separate post-selection unsealing
decision. No model, prior, CAVI equation, ELBO, or initialization method changes.

## Scientific questions

1. With a cross-study shared coefficient function beta_j(t), how accurately
   does multiFSYNC recover beta, the observed/dense signal, and residual
   shared/specific structure under the standard 6--9 irregular time points?
2. Does the answer change when the same covariate-effect size is generated by
   an independently specified cubic B-spline rather than a sinusoid?

The two arms are *paired sensitivity scenarios*, not competing fit methods.
ELBO values are compared only among starts for the same dataset and arm.

## Data and pairing

Six new logical dataset indices 1--6. For index `k`:

- data seed `97201000+k`;
- factor truth-basis seed `97202000+k`;
- loading seed `97203000+k`;
- independent beta B-spline seed `97204000+k`;
- paired fit seeds `97210000+100*k+r`, for `r=1,...,12`.

Each logical dataset has two arms, `sine` and `bspline`, with identical
subjects, covariates, observation times, mean functions, residual factor
functions/scores, loadings, noise, and fitting dimensions. Only the generated
beta_j(t), its contribution, and hence the response change. The same fit seed
is used for start `r` across the two arms of logical dataset `k`.

Common full-size configuration: `S=2`, `n_s=(30,30)`, `p=500`, `d=1`, true and
fitted `L_f=1`, `L_s=(1,1)`, `M_f=2`, `M_s=((2),(2))`, `K=5`, 6--9 irregular
observation times per subject, `sigma_eps=0.3`, `mean_amp=0.6`, `beta_amp=0.3`,
`n_dense=201`, `truth_basis_method="jaoua_splinets"`, and the established
controlled strong-identifiability loading design (`identified_loadings=TRUE`,
`prop_sparse=0.9`). Loading columns receive the established v0F
constant-per-active calibration with anchor 10 active variables and norm 3.
The loading mechanism is the same in both beta arms. Factor score eigenvalue
weights retain the current `1/m^2` mechanism.

The sine arm uses the package generator's `0.3*sin(pi*t+phase_j)` at actual
observation times. The B-spline arm uses a cubic ordinary B-spline basis
(`splines::bs`, fixed internal knots 0.25, 0.5, 0.75, boundary knots 0 and 1,
intercept included). For each variable, seven independent standard-normal
coefficients are drawn under the separately registered beta seed. Its curve is
linearly rescaled to have the sine curve's *continuous-grid mean and centered
L2 RMS* on the common 201-point grid. The B-spline is evaluated directly at
the actual observation times. This is an independent truth representation,
not an O'Sullivan-basis truth or interpolation from the evaluation grid.

The common grid is for truth storage, numerical integration, and scientific
evaluation; it is not held-out data. Effect differences between arms can
therefore be interpreted mainly as shape sensitivity at matched continuous
mean and centered energy, not as a scale/SNR comparison. Exact paired checks
verify equality of all non-beta truth quantities and the response decomposition.

## Fitting and truth-free selection

`6 datasets x 2 arms x 12 starts = 144` independent main fits. Each fit uses
random initialization, G12 Gram unit-function-energy scaling, one pre-score
sweep, Jaoua annealing `c(1,1.9,100)`, 99 annealing sweeps followed by exactly
400 ordinary `T=1` sweeps (`maxit=499`, the established fixed-400 route),
`n_g=51`, `lambda_orth=0`, and `n_cpus=1`. The full 8-vCPU ECS may run up to
eight independent fit processes concurrently **only if** the full-size
preflight shows sufficient memory. No racing, automatic 800 continuation,
truth-based fit choice, or cross-arm ELBO comparison.

For each arm/dataset, select the objective-eligible endpoint with the largest
finite ordinary `T=1` ELBO, tie-broken by lexical `fit_id`. Objective
eligibility is the existing candidate2/G12 contract: completed annealing,
final temperature 1, finite ordinary ELBO and components, valid ordinary
objective, zero ordinary ELBO decreases, and zero ordinary solver jitter.
Strict practical convergence is recorded separately and is not a requirement
for eligibility. Failed/ineligible fits remain recorded; no selective reruns.
If no start is eligible, record no winner instead of consulting truth.

## Staged execution and capacity gate

Before the 144 main fits: (1) retain a pre-change tiny d>0 baseline;
(2) make only the algebraically exact beta-update loop-hoisting repair;
(3) compare beta posterior mean/covariance, mean block, ordinary ELBO and
ELBO components to the baseline, run targeted and full package tests;
(4) run a tiny two-arm generator-to-selection smoke; and (5) on ECS measure
a full-size 8-sweep ordinary `T=1` preflight and peak memory. Preflight is
not one of the 144 main endpoints, is never eligible for selection, and is not
evaluated scientifically. Do not launch the batch if numerical checks fail,
if the memory headroom is unsafe, or if preflight predicts infeasible runtime;
report the measured bottleneck before any further optimization.

Each main fit receives its own directory with full fit RDS, ordinary ELBO,
warnings/error, elapsed seconds, and COMPLETE/ERROR marker. Data are saved as
observation-only bundles plus separately sealed truth bundles. The fit action
loads only observations. Truth-free selection is frozen before any truth access.

## Pre-registered scientific readout after later truth authorization

Primary: beta coefficient-function integrated squared error (including
relative ISE with a declared denominator), beta contribution error at observed
times, observed-time signal NRMSE, dense-grid signal NRMSE, and the gap between
observed and dense reconstruction. Secondary: loading-first shared/specific
identity matching, true residual factor structure, feature/covariance-kernel
recovery, score correlation, factor process/contribution error, warnings,
ordinary ELBO, runtime, and strict practical-convergence status. Report all
12 starts, the truth-free winner, paired arm differences, and per-dataset
variation. Do not claim dimension selection: true and fitted L/M are fixed
here. Six logical datasets are a focused covariate validation, not broad
universal evidence.

If this stage is adversely affected by computational failure or weak recovery,
preserve the evidence and diagnose it; do not silently change the priors,
generator, initialization, or selection rule within this protocol.
