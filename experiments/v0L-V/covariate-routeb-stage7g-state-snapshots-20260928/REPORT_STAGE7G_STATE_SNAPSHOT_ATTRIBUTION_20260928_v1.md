# Stage 7G 全状态快照重放与 B2 关闭归因

日期：2026-09-28。对象是 Stage 7C 已冻结的三个 C1 真值盲 winner：seed01/start06、seed02/start11 为研究 2 特异块 B2 失败例，seed03/start06 为成功对照。本轮只增加每个 sweep 末的原始变分状态记录；不产生正式候选，不改变模型、先验、CAVI、ELBO、输入、起点、维度或选择规则。真值仅在端点复现门槛通过后用于事后评价。

## 1. 结论

**初始真方向对齐不能解释这三条路径的分歧。** 三条的初始绝对载荷余弦分别仅为 `0.0631/0.0952/0.0233`，成功 seed03 反而最低；三条早期 B2 后验均值信号都显著缩小，到 sweep 20 均无 PPI≥0.5 的坐标。seed03 在 sweep 51–60 先把一个**几乎沿真共享载荷方向**的 B2 块重新放大，随后才在 sweep 76–126 获得真 B2 支持并转向其真实特异方向。seed01/02 的 B2 载荷与得分后验均值继续衰减，平均 PPI 到 sweep 63 才低于 0.01，在 sweep 67 数值关闭。

因此，本组三条轨迹显示“**早期均值信号能否重新增长，以及共享与特异方向随后如何重新分配**”是随机路径的主要可见分叉。seed03 的中途 B2 增长并非真特异结构的立即恢复。平均 PPI 接近零的最终关闭发生较晚；软 PPI 从早期已参与更新，现有观察不能证明其作用只在后期，也不能断定单独保护尺度就能修复算法。Stage 7E 已表明 seed01/02 的同一目标存在普通 ELBO 更高、结构正确的局部端点；Stage 7G 进一步定位了登记随机路径如何错过它们，但尚未分清残差几何、共享信号竞争、更新顺序与先验反馈各自的因果作用。

## 3. 三条路径的时间顺序

| 指标 | seed01 失败 | seed02 失败 | seed03 成功 |
| --- | ---: | ---: | ---: |
| 初始 B2 真方向绝对余弦 | 0.0631 | 0.0952 | 0.0233 |
| 得分后验均值 RMS 首次低于真 RMS 的 1% | sweep 5 | sweep 6 | sweep 3 |
| 有效载荷均值范数首次低于真范数的 1% | sweep 10 | sweep 17 | sweep 16 |
| sweep 50：平均 PPI | 0.2232 | 0.2225 | 0.2204 |
| sweep 50：有效载荷均值范数 | 0.000692 | 0.0000723 | 0.811 |
| sweep 50：得分后验均值 RMS | 5.68e-6 | 2.63e-7 | 0.00769 |
| sweep 50：得分后验二阶矩 RMS | 0.952 | 0.951 | 0.947 |
| sweep 50：B2 均值信号 / 真信号 | 5.57e-10 | 4.25e-12 | 5.08e-4 |
| sweep 60：B2 均值信号 / 真信号 | 1.06e-9 | 5.94e-13 | 0.629 |
| 平均 PPI 首次低于 0.01 | sweep 63 | sweep 63 | 从未发生 |

| 末端载荷 `|cos|`；均值信号 / 真信号 | 无定义；0 | 无定义；0 | 0.999666；1.039 |

**均值信号衰减先于 PPI 接近零。** sweep 50 时三条平均 PPI 很接近，但失败两例的 B2 载荷与得分均值、均值因子信号已近零。软 PPI 从早期便参与更新，平均值相近不能排除坐标驱动与门控的反馈。三条的得分**二阶矩** RMS 仍在约 `0.95`，因此这里的“得分关闭”只指后验均值，不能说完整得分后验能量消失。到 sweep 60，seed01/02 的有效载荷均值范数仅为 `4.03e-4/1.02e-5`。此时 seed01 的原始 `|cos|=0.628`，sweep 63–65 两条甚至短暂超过 `0.9`，但范数已经趋近机器零，不能解释为方向恢复。两条从 sweep 66 起同时满足平均 PPI<`1e-4`、有效载荷范数<`1e-3`，sweep 67 有效载荷与得分均值都变为数值零。

**成功路径先增长共享方向，再迁移支持。** seed03 首次重新达到有效载荷范数≥1、得分均值 RMS≥0.01，均在 sweep 51；B2 均值信号首次达到真信号的 1%/10%，分别在 sweep 55/56。sweep 55，PPI≥0.5 的 29 个坐标全部是假阳性；sweep 60，46 个全是假阳性。此时载荷范数 `24.17`、得分均值 RMS `2.143`、信号幅度比 `0.629`，与真 B2 载荷的 `|cos|` 仅 `0.000659`，却与真共享载荷方向的 `|cos|` 达 `0.998726`；拟合共享载荷自身与真共享方向的 `|cos|` 为 `0.998657`。这说明两个拟合块一度共享近似相同的**载荷方向**，不意味着完整的时间函数、个体得分或重构信号重复。真阳性在早期初始化（PPI 全为 0.5）之后曾消失，**衰减后**首次重新出现于 sweep 76，达到至少 25 个在 sweep 81；载荷对真 B2 的 `|cos|` 首次达到 `0.5/0.9/0.99` 分别在 sweep `91/110/122`。到 sweep 99 已有 48 个真阳性，但同时仍有 46 个假阳性；首次达到 48 真阳性、0 假阳性在 sweep 126。普通 `T=1` 阶段从 sweep 100 开始。因此，本例的载荷方向和支持收口跨越退火与普通阶段，且发生在幅值恢复之后。

同一真值对齐表显示，seed03 在 sweep `50/60/91/126` 的 B2 对真共享载荷 `|cos|` 分别为 `0.5521/0.998726/0.8514/0.000134`，对真 B2 为 `0.08057/0.000659/0.5214/0.999619`。失败例的拟合共享载荷在 sweep 40 已对齐真共享方向（seed01/02 为 `0.99918/0.99987`），成功例当时只有 `0.02038`。这是值得追查的学习顺序差异。sweep 60 的 `0.629` 是 B2 重构**幅度比**；只比较该块与真 B2，空间载荷几乎正交给出相对 RMSE 下界 `sqrt(1 + 0.628637² - 2×0.628637×0.000659) ≈ 1.181`，所以它不是“已恢复约 63% B2”的证据。

这一时间顺序反驳“需要从正确方向起步才能成功”的强命题，也反驳“只要 B2 均值信号足够大便已得到正确结构”。它没有告诉我们为什么 seed03 能把错误方向的活跃块转向真方向，而另两条无法重新放大块。

## 4. 时间函数尺度与完整后验信号

失败两例 sweep 50 的拟合 B2 **时间函数均值** L2 仅为 `0.841/1.871`，相对各自真函数也是约 `0.841/1.871` 倍；seed03 为 `0.560`。失败例的均值因子信号同时已趋近零，所以观察不到“把时间函数均值放大来补偿载荷和得分均值缩小”。seed01/02 的原始均值载荷方向也未简单转移到 B1 或 shared：末端 B1 对真 B2 的余弦为 `0.00733/0.04399`，shared 为 `0.000137/0.0000747`；见[其他块对齐表](posthoc_v1/OTHER_BLOCK_ALIGNMENT_TO_TRUE_B2.csv)。这只排除简单的**载荷方向**搬移，不排除其他块、均值或噪声在重构和协方差层面的竞争。

另一个容易误读的现象是：失败路径在 B2 数值关闭后，时间函数**后验二阶矩**的积分 L2 约为 `1.635e5/1.635e5`，远大于其零均值。独立从冻结 Stage 7F 端点重新计算的时间系数协方差积分平方 L2 为约 `2.67267e10/2.67240e10`，最大系数协方差对角约 `1e10`；[独立能量复核](posthoc_v1/ENDPOINT_ENERGY_INDEPENDENT_CHECK.csv)逐项匹配 Stage 7G 机器表。冻结代码的线性系数先验采用 `sigma_beta=1e5`，所以其方差为 `1e10`；B2 载荷二阶矩消失时，时间函数的似然精度项也消失，后验返回这个极宽的线性先验（见隔离源 `stage7g_source/R/utils_multi.R` 的 `set_hyper`、`stage7g_source/R/update_eigenfunctions.R` 的 B2 后验精度）。二阶 L2 从 sweep 65 约 `0.96/2.09` 上升至 sweep 67 约 `134/622`，sweep 69 附近达到约 `1.81e5`，发生在最终关闭附近或之后，而不是最初均值衰减之前。

完整因子后验二阶信号需同时乘入有效载荷二阶矩、得分二阶矩以及时间函数均值和协方差。依据冻结端点的独立重算，seed01/02/03 的 B2 因子产品 RMS 分别为 `3.71656e-7/5.74382e-7/0.314404`，见[完整二阶信号复核](posthoc_v1/FULL_POSTERIOR_SIGNAL_ENDPOINT.csv)。故失败例的巨大时间函数方差**不**表示观测 B2 信号被巨大的时间函数补偿；它表明块关闭后该函数在弱约束方向上的后验不确定性很大。宽先验及其更新反馈是否加强了锁定，仍需因果诊断。

逐 sweep 机器表的 `conditional_second_signal_l2_rms_over_variables` 未计入时间函数协方差，不能用它声称已复核全过程的完整后验因子产品二阶矩。上面的完整二阶矩结论只针对三个端点；极大函数方差主要在最终关闭附近出现，无法解释 sweep 3–20 的最初均值衰减。

## 6. 下一项最小任务与停止规则

下一项建议**只读残差与更新驱动归因**，不重复拟合，优先用已保存的原始状态、绑定观测和 Stage 7F 的逐 sweep driver trace。在 seed01/02/03 的 sweep `20/25/40/50/55/60`，以原观测点、原似然权重和拟合基重建研究 2 的 B2 留出残差：`Y₂ − 拟合均值₂ − Z₂拟合β − 拟合共享信号₂`。当前研究 2 只有 B2 一个特异块；研究 1 的 B1 **不能**从研究 2 的残差中扣除。记录残差主方向与奇异值间隙、B2 当前载荷方向、各坐标数据驱动与后验精度、PPI 及载荷/得分二阶矩；考虑相邻 sweep 的更新顺序，不能把 sweep 末全部参数直接代入中途更新公式。先冻结**不读取真值**的残差与驱动表，再另表计算残差主方向与真共享、真 B2 的角度和支持。检查重构在已有快照与 Stage 7F trace 记录点是否逐项一致；若不一致或残差投影病态，停止归因，先核对公式和尺度。若失败路径残差里仍有稳定、可见的 B2 方向而更新仍把块关掉，再比较驱动、精度与门控；若残差已被其他项吸收，则先审计重构竞争与识别约束。任何算法干预均需另立输入、单一改动、配对预算、最小测试和独立新数据确认，不由此报告自动启动长拟合。
