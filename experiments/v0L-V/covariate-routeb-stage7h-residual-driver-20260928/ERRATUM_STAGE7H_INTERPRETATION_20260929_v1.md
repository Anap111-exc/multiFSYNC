# Stage 7H 机器表字段与机制表述勘误

日期：2026-09-29。本文件补充 [Stage 7H v1 报告](REPORT_STAGE7H_READONLY_RESIDUAL_DRIVER_20260929_v1.md)。原报告、脚本、冻结盲表和真值对齐 v1 均保留。此勘误只读已有机器表，没有重新拟合。

1. [v1 残差真值对齐表](stage7h_20260929_v1/truth_alignment_v1/RESIDUAL_TRUTH_ALIGNMENT.csv)的 `odd/even` 行误填了**全样本**的 `sigma1/sigma2/gap1/gap5`。共 160 条分组行、640 个单元受影响。分组的方向投影使用正确的分组特征向量，没有受影响。[v2 范围修正表](stage7h_20260929_v2_erratum/RESIDUAL_TRUTH_ALIGNMENT_SCOPE_CORRECTED.csv)保持全部 480 行、全部方向投影和 full 行谱值原样，只把分组四字段标为缺失，并新增 `spectrum_scope`。这些缺失值不能解释为零，也不能从已存分组特征向量推算。
2. [归一化驱动表](stage7h_20260929_v2_erratum/NORMALIZED_DRIVER_SWEEP50.csv)按 `‖h_total‖₂ / sqrt(U_mean)` 计算，其中 `U_mean=Σ_i‖C_i ψ ξ_i‖²`。sweep 50 的 seed01/02/03 值依次为 `83.893132/79.945061/86.494724`，原始 `‖h_total‖₂` 则为 `0.004598/0.000514/5.092769`。归一化后差距缩小，使幅值对照值得优先检验；由于噪声精度、残差方向及个体间有符号相消仍不同，它不能证明纯幅值是初始根因。
3. seed03 在 sweep 50 的 `h_total` 对精度加权真 shared/真 B2 方向的绝对余弦为 `0.580/0.064`，应表述为**比真 B2 更接近 shared**。到 sweep 60 的 `0.987/0.0037` 才支持高度对齐真 shared。方向余弦不是 shared 对驱动的因果贡献分解。
4. 取消当前 shared 扣除后驱动仍很小，是**固定当前 `g_i`** 的代数比较；它不能排除过去的 shared 学习改变 `g_i`。时间捕获表逐人平方投影后求和，既消去 `g_i` 的幅值，又没有检验实际驱动 `Σ_i g_iᵀR_{ij}` 的跨人有符号抵消。类似的时间捕获率不能排除时间组织、符号一致性或条件数的差异。
5. 得分精度的迹不能替代实际方向的 `Q_i^{-1}h_i` 收缩。sweep 50 三条 B2 的完整后验乘积二阶 RMS 均约为 `0.007`；失败路径的**均值**产品极小，不应说整个 B2 后验已经消失。若谱重启后再塌缩，目标、精度和 PPI 只是候选解释；初值构造、时间分解、尺度分配及后续块竞争同样须检查。

[生成脚本](make_stage7h_erratum_20260929_v1.R)在输出存在时拒绝覆盖；其内部核验了原表键唯一、480 行投影与 full 谱值完全保留、160 条分组行四字段均缺失，以及归一化驱动的三个回归数值。[完成标记](stage7h_20260929_v2_erratum/ERRATUM_COMPLETE.txt)记录输出范围。
