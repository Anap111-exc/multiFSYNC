existing Stage 6G observation-only bundle. It compares random Gram-unit-energy
initialization (historical label G12) with study-aware residual-FPCA, while
retaining one pre-score sweep, Jaoua annealing and 400 ordinary `T=1` sweeps.

a separate user authorization after truth-free endpoint freezing.
