# 下一版开发数据生成机制与边界说明 v1

文档状态：`development_candidate`  
日期：2026-09-27  
适用范围：下一轮 Route-B 含协变量先导实验  
不追溯修改：v0L-V、Stage 6、Stage 7A、Stage 7B、Route-B 桥接及均值桥接

## 1. 固化目的

本文件把已经通过实现检查、配对桥接和无拟合几何审计的生成机制固定为下一轮开发实验的候选设置。它不是 Git 标签、论文最终冻结或正式执行授权，也不修改模型、先验、CAVI、ELBO、初始化或评价公式。

## 2. 观测模型

对研究 `s`、受试者 `i`、变量 `j`，数据按现有 multiFSYNC 模型生成：

\[
Y_{sij}(t)=\mu_{sj}(t)+\mathbf Z_{si}^{\mathsf T}
\boldsymbol\beta_j(t)+
\sum_{l=1}^{L_f}a_{jl}f_{sil}(t)+
\sum_{l=1}^{L_s[s]}b_{sjl}g_{sil}(t)+\varepsilon_{sij}(t).
\]

其中 `beta_j(t)` 是长度为 `d` 的跨研究共享协变量系数函数向量；共享和研究特异因子过程仍采用方案1的完整函数因子定义。

## 3. 特征函数真值

- 方法：`truth_basis_method = "iid_common_splinet_stiefel"`；
- 公共正交 spline 系统维数：`truth_basis_dim = 8`；
- spline：三次、非周期 Splinets regular 系统；
- 粗糙度权重：`truth_smoothness_alpha = 3`（当前实现中的固定 Route-B 设置）；
- 每个共享或特异因子块从同一个生成分布独立抽取 Stiefel 方向；
- 块内特征函数连续 `L2` 正交；不同块之间不强制函数正交；
- 因子角色不再与固定模板绑定；
- 每条特征函数连续 `L2` 能量为1。

### 边界性质

当前 regular Splinets 构造不是自由边界。无拟合审计确认，在机器精度下：

\[
\phi(0)=\phi(1)=\phi'(0)=\phi'(1)=
\phi''(0)=\phi''(1)=0.
\]

在3,000条审计函数中，93.7%的函数在 `[0,0.1]` 与 `[0.9,1]` 合计只承载不足1%的总能量。该结果是稳定的生成假设，不是实现错误、边界爆炸或接缝异常。后续论文必须明确写为“非周期、零边界 regular Splinets 真值”，不得笼统写成自由边界B样条。

自由边界普通B样条可以作为后续敏感性场景，但本先导不同时改变边界机制，以免把协变量效应检验与新生成器验证混在一起。

## 4. 均值函数真值

- 方法：`mean_truth_method = "independent_splinet"`；
- 公共周期三次 Splinets 系统维数：`mean_basis_dim = 8`；
- 平滑参数：`mean_smoothness_alpha = 1.519826404906808`；
- 每个研究和变量独立生成均值函数；
- 连续积分均值为0；
- 连续 `L2` 能量固定为 `mean_amp^2 * 5/8`，当 `mean_amp=0.6` 时为0.225；
- 周期闭合满足 `mu^(r)(0)=mu^(r)(1)`，`r=0,1,2`。

2,000条无拟合审计未发现周期接缝、导数断裂或边界尖峰。周期B样条均值在小型配对桥接中没有改变残差共享—特异结构的主要恢复结论。该均值仍是周期场景，不代表已经验证任意非周期均值。

## 5. 载荷与得分

本先导主场景保持受控强识别载荷：

- `identified_loadings = TRUE`；
- `bool_sparse_loadings = TRUE`；
- `prop_sparse = 0.9`，即每个因子约10%活跃载荷；
- 延续既有 fixed-90、常数活跃载荷标定；
- 满足主场景所需的共享—特异载荷识别约束。

Jaoua式 `Beta(1,p)` / Bernoulli 支持加独立 `N(0,1)` 非零载荷已经作为独立稳健性机制实现并做过小型桥接，但不在本先导中与协变量设计同时改变。它保留为论文稳健性或困难场景，不取代主强识别场景。

标准化FPCA得分独立生成，方差衰减保持 `1/m^2`。协变量与得分不进行人为正交化。

## 6. 拟合空间与已知错位

- 下一轮主拟合使用 `K=9`；这里 `K` 是 O'Sullivan 非线性惩罚块维数，不是因子数或FPCA截断数；
- `L_f=1`、`L_s=(1,1)`；
- `M_f=(2)`、`M_s=((2),(2))`；
- 当前阶段真实和拟合 `L/M` 一致，不声称完成维度选择。

无拟合审计中，非周期特征函数在典型 `K=9` O'Sullivan空间内的相对L2投影下界中位数为0.146，95%分位数为0.353；因此生成与拟合并非同一函数空间。周期均值的对应中位数为0.0048，是有意的良设 nuisance-mean 场景。

## 7. 证据边界

当前证据支持：

- 生成器实现正确，角色同分布且块内正交；
- `K=9` 是下一阶段暂定主拟合值，但不是普遍最优值；
- 在能到达正确盆地时，载荷、得分、过程和贡献可得到良好恢复；
- 普通ELBO在已有可达层内能选中正确端点。

当前证据不支持：

- 所有数据种子用12个起点必然到达正确盆地；
- 零边界具有普遍科学合理性；
- 周期均值适用于所有实证时间域；
- 当前设置已经解决 `L/M` 维度选择；
- 当前开发结果可以直接当作论文最终Monte Carlo。
