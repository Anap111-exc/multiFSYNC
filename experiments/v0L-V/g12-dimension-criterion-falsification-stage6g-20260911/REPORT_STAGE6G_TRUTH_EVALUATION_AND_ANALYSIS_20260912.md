报告日期：2026-09-12  
实验协议：`G12_STAGE6G_DIMENSION_CRITERION_FALSIFICATION_V1_20260911`  
实验性质：开发期小型判伪筛查，不是论文级 Monte Carlo  
真值状态：在 truth-free 选择和哈希冻结之后，由用户明确授权解封  
拟合状态：解封后新增拟合 0 条，continuation 0 条

## 1. 结论先行

Stage 6G 的预注册主规则未通过判伪筛查。三种生成维度中，重复配对时间点
留出 MSE 加 one-SE 简约规则只精确选对 1/3：

- 真值 `L111/M2`：one-SE 选 `L111/M2`，正确；
- 真值 `L211/M2`：one-SE 选 `L111/M2`，低估第二个共享因子；
- 真值 `L111/M3`：one-SE 选 `L111/M2`，低估 FPCA 截断数。

但本轮不能把失败单独归因于 one-SE。按协议规定的因果顺序，最早的阻断发生
在优化可达性：三个场景的真实维度配置各有 `2 splits x 4 starts = 8`
个端点，共 24 个端点，却没有一个端点完整恢复全部真实共享/特异载荷身份；
整个 120 条候选池也没有一个完整 true-core 或 exact-structure 端点。因此：

1. 本轮确实判伪了“当前四起点拟合加 one-SE 能同时选择最小和非最小生成维度”
   这一完整工作流；
2. 本轮没有单独识别出“若各维度候选都已优化到科学有效盆地，one-SE 是否仍会
   失败”；
3. 当前首要问题不是微调 one-SE，而是先确认新生成机制与时间留出训练条件下，
   G12 在足够起点时能否到达正确结构盆地；
4. 观测点重构较好但结构恢复失败，再次证明重构误差不能替代共享—特异身份评价。

## 3. 实验设计回顾

三个新数据场景均使用 `S=2`、`n_s=(30,30)`、`p=500`、`d=0`、`K=5`、
6--9 个不规则时点、`sigma_eps=0.3`、`mean_amp=0.6`、10% 活跃载荷、
强载荷方向可辨识和 Jaoua/Splinets 真值函数。三个真值分别为：

| 场景 | 生成维度 |
|---|---|
| minimal | `L_f=1, L_s=(1,1), M=2` |
| nonminimal-shared | `L_f=2, L_s=(1,1), M=2` |
| nonminimal-rank | `L_f=1, L_s=(1,1), M=3` |

共同候选网格为 `L111/M2`、`L111/M3`、`L111/M4`、`L121/M2`、
`L211/M2`。每位受试者分别留出中间和相邻上侧时间点；每个拆分后的训练数据
只有 5--8 个时点。每个 `data x split x dimension` 使用四个配对 G12 起点，
固定运行 400 个普通 T=1 sweep，先按同维度最大有效普通 ELBO 选一个起点，
再用两个拆分的受试者聚类 MSE 和 one-SE 进行跨维度选择。

四起点是低成本判伪预算，不等价于目前开发路径建议的 12 起点；两个拆分来自
同一批受试者，也不是两个独立数据重复。

## 4. Truth-free 维度选择

| 真值 | one-SE 选择 | 原始最小 MSE | 真值模型 MSE | one-SE 模型 MSE | 真值在 one-SE 集合内 |
|---|---|---|---:|---:|---|
| `L111/M2` | `L111/M2` | `L121/M2` | 0.103609 | 0.103609 | 是 |
| `L211/M2` | `L111/M2` | `L211/M2` | 0.102961 | 0.103004 | 是 |
| `L111/M3` | `L111/M2` | `L111/M2` | 0.109330 | 0.106707 | 否 |

对应的 held-out response NRMSE 分别约为 0.566、0.555 和 0.571。候选间预测
差异很小：

- minimal 场景中，真实最小模型比 MSE 赢家高 0.000854；one-SE 正确回到最小
  模型；
- `L211/M2` 场景中，真实配置虽为原始 MSE 赢家，但 `L111/M2` 只高
  0.000043，远在 one-SE 容忍范围内，因此简约规则必然选择更小模型；
- `L111/M3` 场景中，真实配置本身比 `L111/M2` 高 0.002622，预测风险并不支持
  真值维度。

三个场景的两个拆分的原始 MSE 赢家均不一致。拆分排名 Spearman 相关依次为
0.8、0.7 和 -0.2；成对排序一致率为 0.8、0.8 和 0.4。尽管如此，逐一删除
任一受试者后，三个场景各 60/60 次 one-SE 仍选择 `L111/M2`。这说明本轮
one-SE 的最小模型选择不是由某一个高影响受试者偶然造成，而是在现有风险差异
下非常稳定的简约偏向。

原始最小 MSE 同样只选对 1/3，而且选对的是另一场景。因此简单删除 one-SE
并不能解决问题。

## 5. 优化可达性与共享—特异身份

本报告使用两个嵌套定义：

- true core：全部真实全局载荷方向和全部研究内角色均被匹配到正确参数块，且无
  真实方向 missing 或 misplaced；允许另有 extra/duplicate；
- exact thresholded structure：在 true core 基础上，还要求没有 PPI 保留的
  extra/duplicate，且保留因子数等于生成真值。

结果为：

| 场景 | 真实配置端点 | true-core | exact structure | 真实特征成分全覆盖 | 最接近端点的全局/研究角色/成分覆盖 |
|---|---:|---:|---:|---:|---|
| `L111/M2` | 8 | 0 | 0 | 0 | 2/3，3/4，6/8 |
| `L211/M2` | 8 | 0 | 0 | 0 | 3/4，5/6，10/12 |
| `L111/M3` | 8 | 0 | 0 | 0 | 2/3，3/4，9/12 |

整个 120 条端点也是 true-core 0/120、exact 0/120、真实特征成分全覆盖
0/120。将载荷匹配阈值从主分析的 0.9 分别降到 0.8、0.7 和 0.6，四个阈值
下仍均为 0/120 true-core，因此结论不是由 0.9 阈值过严造成。

真实配置内的逐方向结果呈现明显模式：

- minimal：第一个共享方向正确 6/8；study-1 特异方向正确 0/8；study-2 特异
  方向正确 0/8；
- nonminimal-rank：共享方向正确 7/8；study-1 特异方向正确 4/8；study-2
  特异方向正确 0/8；
- nonminimal-shared：第一个共享方向正确 8/8，第二个共享方向正确 5/8；
  study-1 特异方向正确 2/8；study-2 特异方向正确 0/8。

一旦方向匹配成功，载荷余弦通常很高：共享方向约 0.99，已匹配特异方向约
0.87--0.96。这说明本轮不是所有估计都完全无信息，而是只恢复了部分强方向，
其余特异方向经常被遗漏、错放或由不相关候选替代。特别是 study-2 特异方向在
三个新数据场景中均未被正确恢复，值得在下一轮因果诊断中优先检查，但本轮数据
尚不能区分这是四起点预算、少一个训练时点、该批真值信号强度，还是初始化/目标
盆地造成的。

## 6. 最终 one-SE 端点的科学质量

下表均为每个场景两个被选拆分端点的均值：

| 指标 | minimal | nonminimal-shared | nonminimal-rank |
|---|---:|---:|---:|
| 观测时点 latent-signal NRMSE | 0.183 | 0.193 | 0.201 |
| dense-grid latent-signal NRMSE | 0.332 | 0.210 | 0.359 |
| 已匹配方向的函数子空间 recall | 0.920 | 0.929 | 0.588 |
| 已匹配成分的 feature ISE | 0.089 | 0.120 | 0.217 |
| factor-kernel relative ISE | 0.089 | 0.148 | 0.408 |
| covariance-operator relative error | 3.231 | 0.650 | 5.439 |
| 已匹配载荷 relative L2 | 0.114 | 0.177 | 0.178 |
| 已匹配载荷 support AUC | 0.941 | 0.938 | 0.925 |
| 已匹配 FPCA score absolute correlation | 0.881 | 0.889 | 0.431 |
| factor-process NRMSE，missing 按 1 | 0.759 | 0.589 | 0.819 |
| complete-contribution NRMSE，missing 按 1 | 0.768 | 0.588 | 0.808 |

这些结果需要同时阅读：

- 三个场景的观测点重构都很好，dense-grid 重构也均小于 1；
- 但完整结构恢复为 0，协方差算子、完整过程和贡献恢复在 minimal 与 rank 场景
  尤其差；
- conditional loading、feature 和 score 指标只评价成功匹配的方向/成分。它们
  较好并不意味着遗漏方向也已恢复；
- rank 场景只匹配 4/12 个真实特征成分，因此其 conditional feature ISE
  不能当作完整函数恢复结果；
- 这正是“重构好但结构错”的情形：多个错误的载荷—过程组合仍可拟合同一有限
  观测数据，但不能据此宣称恢复了真实共享—特异分解。

对非最小真值，真实维度配置的 ELBO 赢家也没有解决这一问题：

- `L211/M2` 真实配置赢家的 dense NRMSE 为 0.242，过程/贡献 missing-as-zero
  NRMSE 约 0.551/0.552；one-SE 欠拟合配置分别为 0.210 和 0.589/0.588。
  真实配置稍改善完整过程，却没有完整恢复身份，且预测/重构并不全面占优；
- `L111/M3` 真实配置赢家的 dense NRMSE 为 0.372，过程/贡献约 0.740/0.738；
  one-SE 的 `M=2` 分别为 0.359 和 0.819/0.808。增加 rank 改善部分过程，却
  没有形成完整结构优势。

## 7. 内部因子和 FPCA 截断收缩

内部 PPI/PVE 没有在本轮稳定地把过大上界缩回生成维度：

- 120 条端点中只有 33/120 的 PPI 保留因子数等于真值；在 24 条真实维度配置
  端点中为 11/24；
- minimal 真值下，`L121/M2` 和 `L211/M2` 分别只有 4/8、2/8 端点把 PPI
  因子计数缩回 `1,1,1`，且即使计数正确也没有完整恢复载荷身份；
- 真实配置的 effective M 与设定 M 一致为 23/24，但这主要说明上界恰好等于
  真值时 PVE 通常保留全部上界，不构成自动选择能力证据；
- minimal 真值拟合 `M=3` 时，每个候选因子的 effective M 平均 2.79，24 个
  候选因子中 19 个停在上界；拟合 `M=4` 时平均 3.17；
- rank-3 真值拟合 `M=4` 时 effective M 平均 3.58，24 个候选因子中 16 个
  停在上界。

因此 Stage 6G 与 Stage 6A 的方向一致：当前 PPI/PVE 更适合作为描述性内部
活跃度，而不足以独自完成因子数和 FPCA 截断数选择。

## 8. Practical convergence、warning 与计算预算

- strict practical convergence：79/120（65.8%）；
- 41 个 warning 全部是“400 sweep 内未满足 practical convergence，标为慢例”，
  没有数值错误或评价错误；
- 已严格收敛与未严格收敛两组的 true-core 均为 0；平均观测 NRMSE 分别为
  0.195 与 0.194，平均 dense NRMSE 为 0.282 与 0.302；
- 在真实维度配置内，19/24 已严格收敛，但仍没有一个 true-core。

因此，未严格收敛不是本轮结构失败的充分解释；把 400 一律延长到 800 也没有
现成证据会恢复全部结构。strict convergence 仍应作为优化诊断，而不应作为科学
质量或 objective eligibility 的替代条件。

计算方面：

- 120 条拟合合计实际单核时间约 85.32 小时，7 路并发的实际墙钟时间约
  12.51 小时，并行利用率约 97%；
- 各配置单条 fit 中位耗时约 33.5--57.7 分钟，`L211/M2` 最慢；
- 每条 fit 峰值内存约 210--214 MiB；
- 120 条科学评价用 7 核只需 38.3 秒，峰值常驻内存约 219 MiB。

8 vCPU/16 GiB 对该并发方案足够；本轮主要成本仍是独立多起点 fit，而不是评价。

## 9. 证据边界

本轮只能作为开发期判伪证据，不能宣称总体维度选择准确率，原因是：

1. 每种生成维度只有一个数据种子；
2. 两个拆分共享同一批受试者，不是独立复制；
3. 每个配置只有四个起点，而正式 G12 科学拟合建议为 12 起点；
4. 拆分拟合使用 5--8 个训练时点，比原始 6--9 时点更稀疏；
5. 使用新的 Jaoua/Splinets 真值函数生成机制，尚需与旧生成机制下的可达性证据
   分开解释；
6. 选择后没有做全数据 refit；
7. 由于正确盆地未出现，本轮无法公平比较“已优化良好的不同维度模型”的准则。

## 10. 下一步工作规划

### 10.1 立即停止扩展当前 one-SE 筛查

按照预注册 stop rule，当前规则 1/3 失败后，不扩大到更多数据种子，不根据已解封
真值修改 one-SE 常数，也不把 raw minimum 临时改成主规则。当前 Stage 6G 应作为
失败但有信息量的开发证据冻结。

### 10.2 先做一个约 2--3 小时的最小可达性因果审计

建议下一阶段只用 minimal 场景、真实 `L111/M2` 配置，另建明确标注为
“post-unseal oracle development diagnostic”的目录：

1. 将两个 holdout split 各从现有 4 起点补到 12 起点，共新增 16 条；
2. 对同一原始 6--9 时点全数据运行 12 个预注册 G12 起点；
3. 总计新增 28 条，仍固定 400 sweep、每 fit 一核、最多 7 路并发；
4. 不做跨维度选择，只回答两个因果问题：四起点是否不足、少一个训练时点是否
   破坏可达性。

预计约 15--17 单核小时，即 7 路并发约 2.3--3 小时。判决规则为：

- 12 起点 holdout 能找到 core：四起点预算不足；
- 只有 full-data 能找到 core：时间留出拟合使结构识别过弱，当前 CV runner 不宜
  直接承担结构维度选择；
- 两者均找不到 core：优先检查新真值生成机制下的特异因子信号与初始化/目标盆地，
  不再优化维度准则；
- 两者都能找到 core：才有资格单独评价维度准则。

这一审计必须获得新的执行授权，因为当前解封授权明确禁止新增 fit；它只能作为
诊断，不能恢复 Stage 6G 的 truth-free 身份。

### 10.3 可达性恢复后，只测试一个理论上不同的维度准则

当前 repeated holdout + one-SE 选择的是“预测有效维度”。当额外真实因子对留出
预测的增益极小，它原则上就会选择更小模型，不能保证恢复生成维度。导师要求的是
模拟中正确选择因子数，因此下一候选应优先审计一个与生成结构更对齐、跨维度可比的
信息准则，而不是继续给 one-SE 叠加阈值补丁。具体先做理论/代码可行性审计：

- 能否得到包含所有跨维度常数的可比 observed-data likelihood 或完整 ELBO；
- 如何定义可辩护的有效自由度；
- AIC/BIC 型准则在该变分功能因子模型中的适用边界；
- 若这些条件不能严谨满足，就明确把 `L/M` 作为外部敏感性参数，并将 CV 解释为
  预测有效维度，而不宣称一致恢复生成真值。

本轮 raw minimum 也只有 1/3，故不建议将其作为那个“唯一替代准则”。

### 10.4 不让维度选择继续阻塞论文主线

完成上述最小可达性审计后，应尽快转入导师明确要求的含协变量模拟：先固定合理的
`L/M`，验证协变量效应、共享/特异结构和重构；维度准则作为一条有明确截止条件的
并行方法线。若一个理论上独立的准则仍失败，应如实把维度选择列为当前模型限制，
而不是无限延长开发实验。

## 11. 最终判决

Stage 6G 的完整工作流结果为 **FAIL（有信息量的判伪）**。当前数据支持以下结论：

- repeated paired holdout MSE + one-SE 不能作为生成 `L/M` 的已验证主准则；
- 本轮最早且更严重的阻断是正确盆地在四起点 holdout 拟合中没有出现；
- PPI/PVE 内部收缩不足以替代外部维度准则；
- strict convergence 与科学正确性仍应分开；
- 重构较好不能证明共享—特异结构恢复正确。

下一步不是扩大 Stage 6G，而是做一次最小、可判别的 12 起点/full-data 对照可达性
审计，然后迅速决定是进入一个独立信息准则，还是承认 `L/M` 选择为论文限制并推进
含协变量主实验。
