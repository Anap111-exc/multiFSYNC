# R-G12 development route v2 candidate

This directory records the post-v0L-V G12 route approved for versioned
development and small paper-pilot use on 2026-08-29.

It supersedes the 2026-08-24 route only for new explicitly registered
development work. Historical v0L-V and G12 protocols remain unchanged. The
candidate uses explicit Gram-unit-energy initialization, one bounded
pre-score, Jaoua annealing, 12 starts, fixed sweep-400 observation, and
truth-free maximum ordinary T=1 ELBO selection.

The candidate is not a formal paper Monte Carlo authorization and is not a Git
release tag.
