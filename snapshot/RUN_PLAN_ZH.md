# 原 CAVI：真实双因子结构的过指定验证

用户已选定10个新数据集，每数据集12个起点，共120条正式拟合。

|项目|冻结设置|
|---|---|
|研究数、人数、变量数|2个研究；每研究60人；500变量|
|真实共享、两研究特异因子数|2、2、2|
|拟合共享、两研究特异因子容量|4、4、4|
|每因子真实／拟合 FPCA 维数|2／4|
|载荷|每列50个非零，平方范数45；每研究各因子支持不重叠|
|真实FPCA方差比例|0.8、0.2|
|噪声标准差、观测次数|0.3；每人6—9次|
|协变量|不生成、不拟合|
|估计器|原 CAVI，无列 MGP；已验收的等价诊断缓存保留|
|初始化|random＋gram_unit_energy＋一次预得分更新|
|迭代|99步退火＋400步普通更新；不设任意墙钟截止|
|正式结果选择|每数据集12起点中，完整有效端点的最大普通ELBO；选择时不读取真值|
|因子数|PPI≥0.5计数；分别报告各块均值、偏差、误差及联合命中率|
|主要科学评价|共享／特异成分、载荷、函数、得分恢复；同时报告MTA/MTB、重构、预测与区间|
|预测数据|同一受试者观测范围内3个新时点；不作为选择集|

数据使用原NC冻结生成器在Linux新生成；不替换为Windows样条基。完整原始状态保留，真值只进入独立评价。

120条拟合前另有固定独立种子200611171的两步资源探针，不进入候选池或科学结论。所有解析、初始化等价、科学评价和资源门槛通过后才启动正式调度。先启动2任务，观测资源后最多8并发，各R进程单线程。失败不更换种子、不自动增加拟合预算。

科学评价在ECS完成后，保存结果和哈希并按既有流程正常StopCharging，不依赖PC开机或文件回传。若出现其他需要实例的任务则不得自动停止。启动不等于运行已完成，最终Stopped须另查云API确认。

本试验是10数据集的可行性验证，不代替论文100次重复；命中率不承诺为100%。
